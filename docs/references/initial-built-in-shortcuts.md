# Initial Built-in Application Shortcut Corpus

This file preserves the user-approved product input for the first built-in plugins. It is source material, not the plugin schema itself. `Ctrl + K, Ctrl + S` means two chords entered in order.

## VS Code

| Shortcut | Description |
| --- | --- |
| `Ctrl + P` | 按文件名快速打开文件 |
| `Ctrl + Shift + P` / `F1` | 打开命令面板 |
| ``Ctrl + ` `` | 显示／隐藏终端 |
| `Ctrl + B` | 显示／隐藏侧边栏 |
| `Ctrl + Shift + E` | 打开文件资源管理器 |
| `Ctrl + Shift + F` | 在整个项目中搜索 |
| `Ctrl + /` | 切换行注释 |
| `Shift + Alt + A` | 切换块注释 |
| `Alt + Up` / `Alt + Down` | 上下移动当前行 |
| `Shift + Alt + Up` / `Shift + Alt + Down` | 向上／下复制当前行 |
| `Ctrl + D` | 依次选择下一个相同内容 |
| `Ctrl + Shift + L` | 选择所有相同内容 |
| `Alt + Click` | 添加多个光标（第一版排除鼠标组合） |
| `Ctrl + Space` | 显示代码补全 |
| `F2` | 重命名变量、函数或类型 |
| `F12` | 跳转到定义 |
| `Alt + Left` / `Alt + Right` | 返回／前进代码位置 |
| `Ctrl + Shift + K` | 删除整行 |
| `Ctrl + K, Ctrl + F` | 格式化选中代码 |
| `Shift + Alt + F` | 格式化整个文件 |
| `Ctrl + K, Ctrl + S` | 打开快捷键设置 |

Essential: `Ctrl+P`, `Ctrl+Shift+P`, `Ctrl+/`, `Alt+Up`, `Alt+Down`, `F2`, `F12`.

Source: [VS Code keyboard shortcuts](https://code.visualstudio.com/docs/configure/keybindings)

## Shared Windows Notes

These applications rarely use Win/Meta shortcuts themselves. `Win+D`, `Win+E`, `Win+V`, and `Win+Shift+S` remain Windows global shortcuts and are merged into every matched application keymap.
